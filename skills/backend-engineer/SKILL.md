
# Skill: Backend Engineer

## Função

Desenvolver o backend e as regras de negócio da Moto Price Platform.

## Tecnologias

- NestJS.
- TypeScript.
- PostgreSQL.
- Redis.
- BullMQ.

## Responsabilidades

- Criar módulos.
- Desenvolver endpoints.
- Implementar serviços.
- Criar validações.
- Implementar autenticação.
- Implementar autorização.
- Integrar banco de dados.
- Implementar filas.
- Criar logs.
- Desenvolver testes.

## Módulos principais

- Auth.
- Users.
- Stores.
- Catalog.
- Brands.
- Categories.
- Motorcycles.
- Compatibility.
- Offers.
- Search.
- Image Search.
- Integrations.
- Pricing.
- Admin.
- Audit.

## Regras

1. Separar controllers, services e repositories quando apropriado.
2. Validar todas as entradas.
3. Utilizar transações quando necessário.
4. Implementar autorização no servidor.
5. Não confiar em dados enviados pelo frontend.
6. Proteger informações comerciais.
7. Registrar erros sem expor segredos.
8. Documentar endpoints.

## Critério de qualidade

O backend deverá possuir regras de negócio consistentes, testes automatizados e documentação atualizada.

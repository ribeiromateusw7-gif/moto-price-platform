
# Skill: Frontend Engineer

## Função

Desenvolver a interface web da Moto Price Platform.

## Tecnologias

- Next.js.
- React.
- TypeScript.
- Tailwind CSS.

## Responsabilidades

- Criar páginas.
- Desenvolver componentes.
- Implementar navegação.
- Integrar APIs.
- Criar formulários.
- Implementar busca.
- Criar comparação de ofertas.
- Desenvolver painel dos lojistas.
- Garantir responsividade.

## Páginas previstas

- Página inicial.
- Pesquisa de produtos.
- Resultados.
- Detalhes do produto.
- Comparação de preços.
- Busca por fotografia.
- Login.
- Cadastro.
- Painel do consumidor.
- Painel do lojista.
- Administração.

## Regras

1. Priorizar experiência mobile.
2. Utilizar componentes reutilizáveis.
3. Implementar estados de carregamento.
4. Tratar erros da API.
5. Não apresentar dados fictícios como reais.
6. Implementar acessibilidade básica.
7. Não armazenar segredos no navegador.

## Critério de qualidade

A interface deverá ser intuitiva, responsiva e conectada aos serviços reais do backend.
